الإزاحة كتكامل للسرعة

الإزاحة كتكامل للسرعة: x = ∫v dt

المعادلة الرياضية:

الإزاحة هي تكامل السرعة بالنسبة للزمن

x(t) = x₀ + ∫v(t) dt

للتسارع الثابت: x = x₀ + v₀t + (1/2)at²

حيث:

  • x(t): الإزاحة النهائية
  • x₀: الإزاحة الأولية
  • v₀: السرعة الأولية
  • a: التسارع
  • t: الزمن

مثال: جسم يتحرك بسرعة أولية 10 م/ث وتسارع 2 م/ث²

الإزاحة x = ∫v dt = ∫(v₀ + at) dt = v₀t + (1/2)at²

بعد 5 ثوانٍ: x = 10×5 + (1/2)×2×25 = 50 + 25 = 75 متر

التكامل: ∫v₀ dt = v₀t، ∫at dt = (1/2)at²

حاسبة التكامل:

العودة إلى قائمة الدروس
